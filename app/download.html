Installing

macOS
  1. Open BioCartoon-macOS.dmg and drag BioCartoon into Applications.
  2. Open BioCartoon from Applications. The app is signed and notarized by Apple, so it opens like any other app.
Windows
  1. Run BioCartoon-Windows-setup.exe. It installs for your user account, so you don't need admin rights.
  2. If Windows shows "Windows protected your PC", click More info and then Run anyway.
  3. Start BioCartoon from the Start menu.
Linux
  1. AppImage: make it executable with chmod +x BioCartoon-Linux-x86_64.AppImage, then run it.
  2. .deb: install with sudo apt install ./BioCartoon-Linux-amd64.deb.
